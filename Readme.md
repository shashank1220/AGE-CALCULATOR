# Age Calculator
A simple web-based Age Calculator built using HTML, CSS, and JavaScript. This minor project allows users to input their date of birth and instantly calculates their age in years, months, and days. It's a great beginner-friendly project to practice working with dates and DOM manipulation in JavaScript.

## Features
1. Input field for selecting date of birth.
2. Calculates and displays:
    1. Age in years, months, and days.
3. Clean UI.

## Technologies Used
1. HTML – for the page structure
2. CSS – for styling and responsive layout
3. JavaScript – for logic and interaction

## How to Use
1. Clone or download the repository.
2. Open index.html in your browser.
3. Enter your birthdate and click the Calculate button.
4. Your age will be displayed below.
